# Life Star

واجهة أولية لتطبيق Life Star باللغة العربية (RTL).

## الملفات
- `index.html`: واجهة التسجيل والدخول.
- `style.css`: التصميم المتجاوب.
- `app.js`: التبديل بين الدخول والتسجيل والتحقق الأولي من العمر والموافقات.

## تنبيه
هذه نسخة واجهة تجريبية وليست مصادقة حقيقية. أزرار Google وFacebook والهاتف تحتاج إلى إعداد Firebase Authentication وربطها قبل استخدام التطبيق فعلياً.
